WINTER WORLD 2027 — AI COMPANION UPDATE

Added:
- AI Companion page with a trilingual interface (English, Uzbek, Russian).
- Suggested prompt chips, chat history saved locally, loading and error states.
- Express backend endpoint POST /api/companion/chat.
- OpenAI API integration with the API key kept on the server.
- Input length checks, limited chat history, basic request rate limiting.
- Vite /api proxy for local development.

Setup:
1. Run npm install.
2. Copy .env.example to .env in the project root.
3. Add your own OPENAI_API_KEY to .env. Do not share it or commit .env.
4. Run npm run dev:all.
5. Open http://localhost:5173.

Backend health check: http://localhost:5000/api/health

Important:
- The AI feature requires an OpenAI API key and may incur API usage charges.
- Never put the API key in src/ or any VITE_ variable.
- npm install timed out in the build environment, so a full Vite production build could not be verified here.
